질의 판결이 직접 참조한 판례와 같은 사건의 상급심이 참조한 판례 중, 검색 풀 안에 있는 판례를 정답으로 삼았습니다. 정답이 1건 이상 있는 판결을 질의로 사용합니다.

이번 표의 비교 방법

GraphRAG·HippoRAG2는 KG를 활용한 검색 결과입니다. 보고서에서 네 KG 검색 방법이 질의의 개체·관계를 찾는 데 사용한 공통 임베딩 모델은 Qwen3-Embedding-0.6B입니다.

Ontology 미적용 비교군은 Sparse(BM25), Dense(BGE-M3의 코사인 유사도)입니다.

집계 범위

보고서의 수집 풀은 30,100건이며, 실행 결과의 KG 색인은 29,595건입니다. 질의 후보 13,446건 중 전체 결과에 기록된 평가 질의는 13,147건입니다.

행정은 일반행정과 세무를 묶은 분야입니다. GraphRAFT는 가사 161건의 부분 결과를 표시하며, 전체 집계와 구분합니다. LightRAG·GraphRAFT는 비용 문제로 전체 데이터 실험을 추가 진행하지 않을 예정입니다.

수치의 출처

제공된 「Feasibility 검증을 위한 샘플 데이터 구축」 2.1.1·2.1.2의 Hit@k 표와 별도 제공된 Sparse·Dense 표를 반영했습니다. 방법명과 수치는 후속 업데이트를 반영했습니다.

현재 확보한 결과를 기준으로 표시하며, 후속 실험 결과가 추가되면 갱신합니다.

지표 읽기

Hit@k는 상위 k개 결과를 기준으로 한 검색 성공률, MRR@10은 상위 10개 내 첫 정답 순위의 역수 평균, Recall@k는 정답 목록 중 상위 k개에서 검색한 비율의 평균입니다.

2026년 10월 30일 추가한 특허 실험에 11월 2일 제공된 GraphRAFT · LightRAG 결과와 11월 3일 제공된 판례 → 판례의 Sparse·Dense·Hybrid 결과를 반영했습니다. 이전 실험과 데이터셋·질의 수가 달라 별도로 표시합니다. 전체 분야의 온톨로지별 비교는 HippoRAG2·GraphRAG 중심으로 확대하며, LightRAG·GraphRAFT는 비용 문제로 전체 데이터 실험을 진행하지 않을 예정입니다.

B0(Sparse) · B1(Dense) · B2(Hybrid)는 Ontology 미적용 비교군입니다. 빈칸은 0점으로 처리하지 않았습니다.
