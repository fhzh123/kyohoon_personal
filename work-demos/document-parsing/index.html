페이지마다 타입을 무시하고 IoU 0.5 이상인 박스를 헝가리안 알고리즘으로 1:1 매칭합니다. 위치 재현율은 매칭된 정답 박스를 전체 정답 박스로 나눕니다. 분류 정확도는 이 매칭 쌍 중 타입이 일치한 비율입니다.

분류 정확도는 위치가 매칭된 박스에 한정한 값입니다. 두 지표를 함께 보고, 과검출·중복과 타입별 오류도 별도로 점검합니다. 현재 타입 기준은 통일 전이므로 분류 정확도 역시 이 조건을 고려해 해석합니다.

현재 AP@0.50을 적용하기 어려운 이유

AP@0.50은 타입이 같고 IoU가 0.5 이상인 예측을 정탐으로 판정합니다. 현재 데이터는 타입 기준이 통일되지 않아, 위치가 맞아도 타입 차이로 오답이 될 수 있습니다.

AP는 예측을 confidence 순으로 정렬하고 순차(greedy) 매칭으로 정탐·오탐을 구한 뒤 정밀도–재현율 곡선의 면적을 계산합니다. 이번 예측에는 confidence가 없어 모두 1.0을 부여했습니다. 따라서 신뢰도 임계값에 따른 작동점을 구분할 수 없고, 계산된 AP도 동점 처리 순서의 영향을 받을 수 있습니다.

이 조건에서는 AP를 COCO식 신뢰도 순위 품질로 해석하기 어려워, 위치 재현율과 분류 정확도를 주요 지표로 사용합니다. 타입 기준과 박스별 confidence를 보완한 뒤 AP 평가를 다시 검증할 예정입니다. COCO 공식 평가 구현 ↗

AFTER VERIFICATION

이후 연구의 확장 방향

검증에서 확인한 병목을 바탕으로 다음 능력을 차례로 고도화합니다.

각 그림은 오류 유형과 개선 목표를 비교한 설명용 도식이며, 실제 모델의 추론 결과가 아닙니다.

  1. 01

    영역 위치 찾기

    필요한 영역을 빠뜨리지 않고 박스로 찾는 능력을 높입니다.

    우선 · Silver 데이터 확대

    현재 1,383페이지의 학습 데이터를 출발점으로, 자동으로 정답을 구성한 Silver 데이터를 늘립니다. 문서 종류와 레이아웃을 넓히고 학습량을 단계적으로 확대합니다.

    생성 품질 함께 점검

    중복 문서와 명백한 박스 오류를 걸러내고, 생성 결과를 표본 검수합니다. 데이터 양과 함께 누락·경계 오류의 양상도 살펴봅니다.

    확인 · 학습량과 위치 재현율

    고정한 Gold 평가셋에서 학습량별 위치 재현율을 비교해, Silver 확대가 필요한 영역을 더 잘 찾는 데 도움이 되는지 확인합니다.

    위치 재현율 · 누락·중복 분석
  2. 02

    타입 정확히 구분하기

    찾은 영역을 일관된 타입 기준에 따라 구분하도록 개선합니다.

    단기 · Gold의 타입 정책 정립

    타입별 정의와 경계 사례, 분류가 겹칠 때의 우선순위를 정합니다. Gold 라벨을 같은 규칙으로 정비해 무엇을 정답으로 볼지부터 일관되게 맞춥니다.

    학습·평가 기준 맞추기

    정립한 타입 정책을 학습 타깃에도 반영하고, 위치가 맞는데 타입만 다른 오류를 나누어 봅니다. 타입별 혼동과 분류 정확도로 효과를 점검합니다.

    장기 · 타입 체계도 입력으로

    사용자가 원하는 타입 목록과 정의를 입력으로 전달하는 방향으로 확장합니다. 분할 정책을 바꾸듯, 요청에 맞춰 분류 체계도 바꿀 수 있는 것이 최종 목표입니다.

    타입 기준 통일 · 분류 정확도
  3. 03

    출력을 안정적으로 완성하기

    반복과 중단을 줄여 구조화된 출력(JSON)을 끝까지 생성하도록 합니다.

    검토 · JSON 전용 Decoder

    영역 정보를 JSON으로 완성하는 소형 Decoder를 별도로 두는 방안을 검토합니다. 반복 생성이나 중간 종료로 JSON을 읽지 못하는 병목을 우선 대상으로 삼습니다.

    반복·종료 제어 함께 검토

    반복 감지, JSON 스키마 제약과 종료 조건을 함께 검토합니다. 별도 Decoder와 기존 생성 방식에서 중복 항목과 미완성 출력이 어떻게 달라지는지 비교합니다.

    확인 · 형식과 내용 함께

    유효 JSON 비율과 실패 포함 위치 재현율을 함께 확인합니다. 형식이 완성되는 것과 필요한 박스 정보가 보존되는 것을 같이 평가합니다.

    유효 출력 비율 · 반복·중단 점검
  4. 04

    정책을 일관되게 실행하기

    요청한 세분화 수준과 병합 규칙을 안정적으로 따르도록 확장합니다.

    우선 · 정책별 Silver 확대

    같은 문서라도 정책에 따라 분할·병합 결과가 달라지는 학습 쌍을 늘립니다. Silver 데이터로 다양한 문서와 규칙 조합을 확보하는 방향을 우선 검증합니다.

    대안 · 별도 이미지 Encoder

    문서의 시각적 레이아웃 특징을 별도 이미지 Encoder로 추출하고 정책 정보와 결합하는 구조도 검토합니다. 데이터 확대와 구조 변경의 효과를 나누어 비교합니다.

    확인 · 정책 전환의 일관성

    동일 문서에서 정책만 바꿨을 때 요청한 분할·병합 규칙이 출력에 반영되는지 봅니다. 위치 일치와 규칙 준수를 함께 점검합니다.

    정책별 분할 변화 · 규칙 준수

출력 안정성은 전 단계에서 함께 점검하며, 정책 준수 평가를 위한 공통 기반으로 다룹니다. 각 단계의 고도화는 가능성 검증에서 확인한 병목을 바탕으로 이어갑니다.
