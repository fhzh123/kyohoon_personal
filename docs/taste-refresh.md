# 홈페이지 디자인 정리

## 검증 상태

`GATE: ERROR` — 검증용 Chrome이 실행되지 않아 consistency와 layout 검사를 완료하지 못했다. 화면 검증을 통과했다고 간주하지 않는다. 스크린샷, 반응형 배치, 실제 글꼴 로딩, hover 및 성능은 미확인이다.

홈, 업무 홈, 데모, 개인 공간, 로그인 정적 HTML을 대상으로 한 Taste Skill copy-lint 결과는 모두 0 FAIL, 0 WARN이다. TypeScript 검사와 Resume 빌드가 통과했다. 보안, 서버 어댑터, 공간, 연구 기능 검사 41개와 Resume 기능 검사 7개가 통과했다.

로컬 사본에 없는 기존 WebP 이미지는 원격 저장소의 파일을 그대로 참조한다. 새 이미지나 사진 대체물을 추가하지 않았다. 전체 배포 빌드는 Vercel에서 확인한다.

## 변경 내용

- 홈의 추상적인 소개를 이름, 직무, 실제 연구 주제로 바꿨다. 세 공간은 큰 유리 카드 대신 구분선으로 나눈 이동 목록으로 구성했다.
- 영문 대문자 라벨, 기능과 무관한 순번, 슬로건, 이미지 주변의 광원과 궤도 장식, 은하수 애니메이션을 화면에서 제거했다.
- 업무 홈과 데모는 각 도구의 용도와 실행 경로를 바로 표시한다. 로그인과 개인 공간의 상태 안내도 사실 중심으로 바꿨다.
- 연구일지의 화면 제목과 폼 안내를 작업 이름으로 바꿨다. 품의 사용내역은 조회 대상과 집계 내용을 설명한다.
- 중립적인 배경과 표면, 한 가지 파란 강조색, 공통 간격과 컨트롤 형태를 적용했다. 카드의 움직임은 원본 Taste motion 레이어를 사용한다.
- Resume는 원본 내용과 탭, 모달, 언어 전환 기능을 유지하고 배경, 표면, 그림자와 강조색을 정리했다.

## 디자인 결정과 적용 범위

유형은 개인 연구자 포트폴리오와 업무 도구로 판단했다. 문체는 사실 중심이며, 업무 화면은 짧고 직접적인 안내를 사용한다. 색상 선택 결과인 cool-grey-cobalt를 바탕으로 기존의 라이트 및 다크 모드를 함께 유지했다. 새 수치, 실적, 일정, 고객, 사진은 만들지 않았다.

직전에 사용자가 지정한 Pretendard와 주요 제목의 Black 굵기, 기존 마스코트는 유지했다. 글꼴을 임의의 추천 페어링으로 바꾸지 않았다.

개인 홈페이지의 공간 이동과 업무 화면은 판매용 랜딩 페이지와 목적이 다르므로 여러 화면 길이의 홍보 섹션이나 별도의 scroll moment를 추가하지 않았다. 선택된 split 구성은 홈의 소개와 이동 목록에 적용했다. word-highlight moment는 넣을 실제 설명이 없어 사용하지 않았다. 이는 전체 Taste 규칙의 무조건적인 준수를 주장하는 작업이 아니다.

기존 로그인, 권한 확인, 저장 및 데이터 모델은 변경하지 않았다. 기존 연락처와 실제 외부 데모 주소를 유지했다. 새 폼, 가정한 정보, 사진 대체물, 면제 처리 파일은 없다.
