# 홈페이지 및 Resume 보완

## 반영 내용

- 업무 카드의 이미지 영역을 고정 크기로 만들고 이미지를 그 안에 제한했다. 320, 390, 768, 1024, 1440px에서 이미지와 본문이 겹치지 않는다.
- 홈, 업무 홈과 Resume 상단에 일관된 선형 아이콘을 붙였다. Resume 항목은 키보드로 실행 가능한 버튼으로 바꿨다.
- 다크 배경은 기존 은하수 이미지를 흑백으로 낮게 표시하며 300초 동안 천천히 움직인다. 배경 일시정지 버튼과 reduced-motion 대응을 추가했다. 라이트 모드는 밝은 색 번짐과 옅은 패턴을 사용하며 Resume에는 별도 선 패턴을 적용했다.
- 기존에 만든 마스코트 얼굴 파일을 복구해 브라우저 탭, 홈 로고와 Resume 이름 옆에 연결했다.
- 카카오톡, 텔레그램과 Google Scholar 아이콘은 로컬 SVG로 제공한다. 출처와 라이선스는 public/icons/icons-credits.json에 기록했다.
- International Paper 맨 위에 KG-Neighbor를 추가했다. 제목과 저자 순서는 arXiv:2611.07246에서 확인했으며 WSDM 2027 Findings 채택 정보는 사용자가 제공한 사실이다.
- Copyright는 2026년으로 바꾸고 공통 푸터의 개인 홈페이지 문구를 삭제했다.
- Resume에 홈과 공유하는 다크/라이트 전환과 설정 저장을 연결했다.

## 직접 수정할 프로젝트

다음 6개 제목 앞에 `(수정예정)`을 붙였다. 목록 설명과 모달 설명은 `수정 예정입니다.`로 바꾸고 복사된 삼성생명 이미지, 부제, 기관, 역할과 기사 링크를 비웠다. 삼성생명 C-Lab 항목 자체와 그보다 오래된 프로젝트는 유지했다.

1. DATUMO 플랫폼 내 모니터링 대시보드 개발
2. Agentic Flow를 활용한 Dialouge Topic Segmentation
3. 자동 프롬프트 튜닝을 통한 Generalized Category Discovery
4. 기업 문서 내 텍스트, 이미지, 표 추출을 위한 OCR & DLA 원천기술 개발
5. 독자 AI 파운데이션 모델 프로젝트 (SKT 컨소시엄)
6. (경기도 교육청) AI-데이터 중심의 경기교육 디지털 플랫폼 사업

편집 위치: `legacy/resume/src/projectsData.js`. 상세 내용을 채운 뒤 제목의 접두어를 지우면 된다.

## 검증

- 전체 빌드, Resume 컴파일, TypeScript와 JavaScript 구문 검사 통과.
- Resume, 업무 홈, 연구 기능, 서버 어댑터, 접근 제어 및 테마 검사 56개 통과.
- 실제 Chromium에서 홈/업무 홈/Resume의 다섯 화면 폭을 확인했다. same-origin srcdoc 프레임으로 각 실제 뷰포트를 만들었으며 운영 인증이나 프레임 보호 헤더는 변경하지 않았다. 가로 넘침, 로컬 이미지 누락, 업무 카드 이미지/글자 겹침 없음.
- 실제 브라우저에서 다크/라이트 전환, 마스코트/연락처 표시, 새 논문 표시 확인. 기존 모달, 언어 변경과 배경 정지/설정 저장은 DOM 기능 검사로 추가 확인했다.
- 공통 화면 5개의 문구 검사: 0 FAIL, 0 WARN. 변경된 스타일시트 파싱 통과.
- 과거 source-manifest.json은 원본 이관 시점의 기록으로 유지한다. 현재 편집 가능한 소스 전체를 과거 해시와 비교하던 검사는 보존 정적 자산을 확인하도록 조정했으며 변경된 화면과 데이터는 별도 동작 검사로 검증했다.
- 전체 마케팅 페이지의 강제 화면 높이, 새로운 글꼴/색상 무작위 선택 등은 이번 보완 범위에 적용하지 않았다. 사용자가 지정한 Pretendard, 검은 배경, 기존 내용과 업무 도구 구조를 우선했다. 정식 Taste headless gate 통과를 주장하지 않으며 위 실제 브라우저 검사 결과를 기록한다.

## 작업 시간 표시

ChatGPT 앱의 작업 시간 표시는 이 저장소 코드에서 제어하지 않는다. 정지 뒤 카운터가 남는 현상은 앱 내부 실행 상태를 조회할 수 없어 원인을 확정하지 못했다. OpenAI 공식 문제 해결 안내는 멈춘 작업 표시에서 화면 새로고침 또는 앱 재시작을 권장한다.
