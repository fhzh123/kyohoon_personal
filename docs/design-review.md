# 디자인 기준과 이미지 검토

검토 역할: 실제 Claude B가 아닌 내장 Codex 대체 담당. 원본 마스코트 v9 README, 정면 대기 PNG와 두 생성 PNG를 직접 열어 검토했다. 홈페이지 Draft Markdown·PDF는 현재 찾지 못했으므로 Draft 기반 검토로 보고하지 않는다. 공통 이미지 제작 기준은 총괄이 확정해 Codex C·D에 전달했으며, 이 기록은 생성 결과의 일관성 검토다.

## 마스코트

- 보존 특징: 흰 둥근 후드와 큰 머리, 광택이 있는 검은 화면, 세로로 긴 하늘색 눈 두 개, 화면 오른쪽으로 기운 회색 머리 핀, 오른쪽 위 파란 패치, 파란 후드 끈과 오른쪽 엉덩이 뒤 꼬리, 흰 벙어리장갑 손과 짧은 다리·둥근 신발.
- 그림체: 부드러운 3D 장난감 재질, 흰색·회색·청색 고유 팔레트, 정면 카메라와 중립적인 부드러운 조명.
- 두 생성 장면에서 얼굴·색상·의상·장식의 방향이 일치한다. Resume는 열린 손과 파란 폴더, Work는 노트북·종이·작은 책상이어서 용도가 구별된다. UI 문자는 없다.
- 두 파일은 정사각형 투명 PNG다. 동일한 1:1 이미지 슬롯에서 `object-fit: contain`으로 전체를 표시한다. 최초 적용 폭은 Resume 90%, Work 96%를 권장하고 실제 화면에서 머리 크기를 비교한다. 책상이 있는 Work를 잘라 맞추지 않는다.
- 두 이미지 가장자리에 미세한 밝은색·청색 프린지가 보인다. 검은 배경에서는 보이지만 밝은 파란 배경에서는 덜 두드러진다. 현재는 눈에 띄는 캐릭터 불일치가 없어 재생성을 권하지 않는다.
- 원본은 Assets와 생성 원본 폴더에 보존하며, 웹용 사본만 public/mascot에서 사용한다. 새 이미지 제작 시 동일한 정면 참조를 사용한다.

## 메인과 Work의 새 UI

Resume 문서는 이 기준의 적용 대상이 아니다. 원본 Resume의 전역 CSS와 새 UI 스타일을 문서 단위로 분리한다.

| 항목 | 기준 |
|---|---|
| 페이지 배경 | `#F3F7FE` |
| 카드·읽기 면 | `#FFFFFF` |
| 이미지 패널 | `#EAF2FF` |
| 본문 | `#142B4F` |
| 보조 글자 | `#536984` |
| 강조·선택 | `#245CD6` |
| 경계선 | `#D5E1F3` |
| 본문 글꼴 | 기존 자산의 WantedSans-Medium + 한국어 시스템 sans-serif 폴백 |
| 본문 | 16px, line-height 1.7, 긴 제목 `overflow-wrap: anywhere`, 한국어 문단 `word-break: keep-all` |
| 메인 제목 | 데스크톱 48~56px, 모바일 32~38px, line-height 1.2 |
| 선택 카드 제목 | 28~32px, 설명 16px |
| 최대 콘텐츠 폭 | 1100px |
| 데스크톱 카드 간격 | 24px, 카드 내부 28~32px |
| 모바일 | 720px 미만 한 열, 바깥 여백 20px, 카드 내부 24px |
| 모서리 | 카드 24px, 작은 버튼 10~12px |
| 키보드 초점 | 3px `#245CD6` outline, offset 5px |
| 움직임 | hover 140~180ms, 이동 최대 3px; reduced-motion에서는 이동·애니메이션 제거 |

메인의 핵심은 위쪽 이미지와 아래쪽 제목·설명이 결합된 큰 링크 두 개다. `<a>` 하나가 카드 전체를 감싸도록 하며 카드 안에 별도 버튼·링크를 중첩하지 않는다. 작은 화살표는 장식으로 표시하고 접근 가능한 이름은 카드 제목과 설명으로 구성한다. 마스코트가 이미 메시지를 전달하므로 불필요한 상태 숫자나 메뉴를 추가하지 않는다.

최초 이미지 검토 시점에는 Draft가 없었다. 이후 추가된 Draft에 따라 Work 첫 화면을 7개 업무 도구 영역의 허브로 구현했다. 연구일지·두 연구 데모가 활성화되며 나머지는 공사 중이다. 기존 연구 기획 화면은 첫 연구일지로 연결하며 허브를 일반 대시보드로 바꾸지 않는다.

## 검증 범위

이미지 파일을 직접 보았으며 브라우저 내 실제 크기·모바일·focus 상태는 이 기록 작성 시 아직 확인하지 않았다. 이 문서만으로 브라우저 시각 검증 완료를 뜻하지 않는다.
