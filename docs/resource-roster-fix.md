# 담당자 리소스 목록과 MM 기준 표시

담당자 카드는 현재 기간의 L5 집계 결과에서만 생성하고 있어, L4만 맡았거나 현재 기간에 L5가 없는 담당자가 목록에서 빠졌다. 전체 연구의 담당자를 기준으로 카드를 생성하고 기존 L5 계산 결과를 연결한다. 현재 기간에 배정이 없는 경우 0%, 0.00 MM과 안내를 표시하며, 실제 L5의 리소스 미입력은 기존처럼 미입력과 MM 미산정으로 구분한다.

담당자 수를 제목 옆에 표시한다. 담당자 필터가 적용됐으면 그 사실도 함께 표시한다. L4만 담당하는 사람도 순서를 바꾸고 저장할 수 있다. 입력된 담당자의 수에 제한을 두지 않으며 너비에 맞춰 카드가 줄바꿈된다. 기존 L5 MM과 초과 배정 계산은 변경하지 않았다.

MM 계산 기준 문단의 `max-width: 90ch` 제한을 제거했다. 펼친 내용은 전체 너비를 쓰는 반응형 그리드로 배치한다. 화면이 좁아지면 열 수가 줄어들고 각 문단은 내용만큼 높이가 늘어난다.

프로덕션 빌드 성공. 연구 기능 52개와 DOM 통합 및 가져오기 3개, 총 55개 검사 통과. 8명 목록, 현재 배정 없음과 미입력 구분, L4 담당자 순서 저장, 기간 전환, 월간 일정, 담당자 필터와 기존 MM 수치를 검증했다. 목록을 표시하는 과정에서 연구 데이터가 저장되거나 변경되지 않는지도 확인했다.

검증용 Chrome이 실행되지 않아 화면 캡처를 완료하지 못했다. 실제 브라우저의 반응형 배치나 다크 모드 렌더링을 확인했다고 간주하지 않는다.
