# 마지막 활동 이후 3시간 로그인 유지

사용자가 글을 입력하거나 클릭, 스크롤, 터치, 페이지 이동을 하면 마지막 활동 시간을 갱신한다. 마지막 활동으로부터 3시간이 지나면 해당 브라우저에서 로그아웃한다. 자동 저장, 상태 조회, 토큰 갱신, 문서 미리 가져오기는 활동 시간을 연장하지 않는다. 여러 탭은 활동 시간을 공유하며, 잠자기에서 돌아왔을 때도 기존 만료 시간을 먼저 확인한다.

로그인 상태의 HTML에 공통 활동 추적 스크립트를 넣는다. 활동 시간은 브라우저에서 즉시 반영하고 서버에는 최대 30초 간격으로 전달한다. 서버는 기존 HttpOnly 세션 자격 정보로 서명한 활동 시각을 검증하고 보호 경로에서 3시간 제한을 적용한다. 새 환경 변수나 데이터베이스 변경은 없다. 기존 로그인에는 첫 검증 시 활동 기준을 초기화하므로, 이미 열려 있는 화면은 한 번 새로고침해서 새 추적 코드를 불러와야 한다.

인증 쿠키가 1시간 뒤 사라져도 갱신 쿠키로 재인증한다. 토큰과 활성 회원 권한을 다시 확인하며, 인증 토큰 자체의 유효 기간을 늘이지 않는다. 갱신은 기존 활동 시각을 보존한다. 동시에 들어온 갱신 요청은 한 실행 인스턴스에서 공유한다. 일시적인 인증 서버 장애와 요청 제한은 재시도할 수 있는 오류로 반환한다.

한 탭의 만료 요청이 다른 탭의 최근 활동을 덮어쓰지 않도록 서버에서 현재 만료 시각을 다시 확인한다. 자동 로그아웃은 해당 브라우저의 인증 쿠키만 제거하며, 다른 기기의 Supabase 세션을 강제로 취소하거나 기존 로컬 작업 저장소를 지우지 않는다. 수동 로그아웃의 기존 동작은 유지한다.

공통 HTML 주입은 gzip 데모 응답을 해제한 뒤 다시 압축해 전송한다. 익명 HTML이나 인증되지 않은 응답에는 추적 코드를 넣지 않는다. 브라우저 스크립트와 HTML에는 인증 토큰을 포함하지 않는다. 새 활동 및 만료 API에도 기존 동일 출처 검사를 적용한다.

인증, 권한, 로그인, Resume 세션, Vercel 어댑터, 압축 데모 및 새 유휴 시간 검사 총 50개 통과. 모의 시계로 1시간 초과 사용, 정확한 3시간 만료, 활동 시 연장, 자동 통신 제외, 잠자기 복귀, 다른 탭의 활동, 갱신 동시성, 잘못된 서명과 출처, 인증 서버 장애를 검증했다. 프로덕션 빌드도 통과했다. 검사는 모의 Supabase 응답과 DOM 이벤트를 사용하며 실제 계정으로 장시간 로그인 상태를 관찰한 검증은 아니다.

기존 인증 테스트의 로그인 기본 도착지 기대값은 이미 적용돼 있는 Home 기본 동작에 맞춰 정리했다. 별도의 로그인 이동 정책 변경은 없다. 전체 테스트에 남아 있는 기존 홈페이지와 이력서의 기대값 불일치는 이번 인증 변경에 포함하지 않았다.
